## 🎓 Key Concepts Explained

### 'use client' Directive
- Add `'use client';` at top of files using React hooks/state
- Makes component render on client side (interactive)
- Required for: useState, useContext, useEffect, event handlers
- Optional for: Static display components

### App Router vs Pages Router
- **App Router** (recommended) - File-system routing in `app/` folder
- **Pages Router** (old) - File-system routing in `pages/` folder
- This project uses: **App Router**

### Server Components vs Client Components
- **Server Components** - Render on server, send HTML (default)
- **Client Components** - Render in browser, interactive (need `'use client'`)
- Mix and match: Server for data, client for interactivity

### API Routes
- Create backend endpoints without separate server
- Location: `app/api/*/route.ts`
- Can access databases directly
- Automatic serverless functions
